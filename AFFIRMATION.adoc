== What this is, and how it works

bofig (Binary-Origami Figurator) is an Elixir/Phoenix evidence graph for
investigative journalism. Claims, evidence and relationships are stored in
ArangoDB (document and graph). Accounts and other relational data are stored in
PostgreSQL through Ecto. An Absinthe GraphQL API sits on top, with PROMPT
epistemological scoring and audience-weighted navigation paths. This file is a
dated receipt for the commit in <<verifiable-anchor>>. It reports which checks
were run against that commit, what each one returned, and which repository
documents disagree with those results.
