== Key Claims From README

[quote, README section "Vision"]
____
We didn't fall from Truth to Post-Truth; we evolved to complex epistemology without building infrastructure. *This system IS that infrastructure.*
____

*Evidence:* The project implements three interdependent epistemological systems (lines 62-72):
1. **PROMPT Framework**: 6-dimensional epistemological scoring (Provenance, Replicability, Objective, Methodology, Publication, Transparency) with audience weighting
2. **i-docs Navigation**: Interactive document navigation enabling reader agency and multiple perspectives
3. **Boundary Objects**: Same evidence folded into different forms for different audiences (researcher, policymaker, skeptic, activist, affected person, journalist)

The implementation is proven by the test dataset (UK Inflation 2023) with 7 claims, 30 evidence items, and 38 relationships across 3 navigation paths (lines 318-331). Each path weights PROMPT dimensions differently per audience type, proving the infrastructure exists.

*Caveat:* The system enables multiple perspectives but does not resolve disagreement — it makes epistemology visible and navigable, not unified.

[quote, README section "Quick Start" and "Project Structure"]
____
Implemented (v1.0.0): Multi-model ArangoDB integration (document + graph), GraphQL API with Absinthe (15 queries, 11 mutations), PROMPT epistemological scoring (6 dimensions, audience weighting), Claims, Evidence, Relationships, Navigation Paths data models
____

*Evidence:* The project structure (lines 272-306) shows functional implementation:
- `lib/evidence_graph/` — 43 Elixir modules (claims, evidence, relationships, navigation, ArangoDB client, PROMPT scoring)
- `lib/evidence_graph_web/` — Phoenix web layer with Absinthe GraphQL schema
- `priv/repo/seeds.exs` — UK Inflation test data loaded
- 257 tests (line 418), 0 failures
- Full RSR compliance (line 418)

The GraphQL examples (lines 124-270) demonstrate working queries and mutations for claims, evidence chains, navigation paths, and Zotero imports.

*Caveat:* Phase 1 (v1.0.0) is production-ready for single investigations. Phase 2 (migrations to Lithoglyph, browser extensions, multi-investigation dashboards) is in design stages.
