|
|===

[NOTE]
====
*SUS Scoring Method (for researchers only -- not shown to participants):*

For odd-numbered items (A1, A3, A5, A7, A9): score = response - 1

For even-numbered items (A2, A4, A6, A8, A10): score = 5 - response

SUS Score = sum of all scores x 2.5 (yields 0-100 scale)

*Interpretation:* Score >= 68 is above average usability. Score >= 80.3 is
Grade A. Score < 50 indicates significant usability problems.
====
